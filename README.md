
# Sales Performance Analytics Dashboard

## Overview
This project is an interactive Power BI dashboard developed to analyse retail sales performance, profitability, and regional business trends.

## Tools Used
- Power BI
- DAX
- Power Query
- Excel/CSV

## Dashboard Features
- KPI cards for Sales, Profit, Orders, and Profit Margin
- Monthly sales trend analysis
- Regional revenue comparison
- Product category profitability analysis
- Interactive filters and slicers

## Key Insights
- West region generated the highest revenue
- Technology category achieved strong profitability
- Monthly sales showed seasonal trends
- Furniture category delivered lower margins
